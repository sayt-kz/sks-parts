Настройка доступа

Для владельца сайта. Ключ GitHub шифруется паролем и хранится на сайте только в зашифрованном виде. Тем, кто работает в админке, нужен только пароль.

Где взять ключ доступа
  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Resource owner — владелец репозитория; Repository access: Only select repositories → репозиторий сайта.
  3. Permissions → Repository → Contents: Read and write.
  4. Скопируйте ключ и вставьте сюда.

Категории

Категории видны в меню «Категории», на главной странице (плитки с картинками) и в фильтрах каталога. «Тип насоса» — у каждого товара ровно один тип. «Разделы по технике» — у товара может быть несколько разделов (галочки в карточке товара). Порядок здесь = порядок на сайте.

Подбор по технике

Марка → модель техники → какие насосы на неё подходят. Эта таблица используется на странице «Подбор» и в ИИ-помощнике. «Синонимы» — как клиенты пишут марку (через запятую), например: хендай, хюндай.

Резервная копия каталога

Скачайте файл каталога перед большими изменениями. Если что-то пойдёт не так, его можно загрузить обратно и сохранить на сайт.

Сменить пароль

Старый пароль перестанет работать через 1–5 минут, когда сайт обновится. Если нужно закрыть доступ полностью (например, ключ мог попасть к посторонним), создайте в GitHub новый ключ, вставьте его ниже, а старый удалите в GitHub.
