# SKS PARTS — сайт-каталог

Чистый HTML/CSS/JS без библиотек и конструкторов. Сайт — `index.html`, каталог — `data/catalog.json`, фото — `img/`, админка — `admin.html`.

## Страницы
`#home`, `#about`, `#pick`, `#catalog` (фильтры в адресе: `?type=axial&tech=excavator&q=k3v`),
`#p-<id>` (товар), `#services`, `#contacts`. Ссылку на любую страницу можно отправить клиенту, кнопка «назад» работает.

## Админка — добавлять и менять товары
Адрес: **https://sayt-kz.github.io/sks-parts/admin.html** (на сайте ссылки на неё нет).

Что умеет:
- **Товары:** добавить, изменить, дублировать, удалить; название, серия, тип, разделы каталога, применение, описание, коды на шильдике, кросс-номера (техника → номера → источник).
- **Фото:** загрузить с компьютера или телефона — админка сама уменьшит до 900 px и сохранит в `img/`; подпись на фото («фото серии», «фото похожего насоса» и т. п. или без подписи, если фото точное).
- **Подбор по технике:** марки, модели и какие насосы на них подходят; синонимы марок для ИИ-помощника.
- **Резервная копия:** скачать каталог файлом и загрузить обратно.

Как работает: кнопка «Сохранить на сайт» записывает фото и `data/catalog.json` прямо в этот репозиторий через GitHub API. GitHub Pages пересобирает сайт, изменения видны через 1–5 минут. ИИ-помощник берёт каталог из того же файла.

### Ключ доступа для входа
Вход — по ключу GitHub (fine-grained personal access token) с правом записи только в этот репозиторий:
1. GitHub → Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate new token.
2. Repository access: **Only select repositories** → `sayt-kz/sks-parts`.
3. Permissions → Repository permissions → **Contents: Read and write** (остальное не нужно).
4. Срок действия — например, 1 год. Скопировать ключ и вставить в админку.

Ключ хранится только в браузере, где вошли (галочка «Запомнить» — до выхода, без неё — до закрытия вкладки), и отправляется только на api.github.com. Если ключ утёк — удалить его в настройках GitHub и выпустить новый.

## ИИ-помощник
- `AI_ENDPOINT = ""` в `index.html` → демо-режим, готовые ответы по каталогу.
- Боевой режим: развернуть `worker/` на Cloudflare Workers и вписать его адрес в `AI_ENDPOINT`.

```bash
cd worker && npm install
npx wrangler kv namespace create SKS_KV
npx wrangler secret put ANTHROPIC_API_KEY
npx wrangler deploy
```

Ключ API хранится только в секретах Worker, в коде страницы его нет.
Лимиты — в `wrangler.toml`: `MAX_MSG_PER_HOUR` (с одного IP) и `MONTHLY_LIMIT_USD`. Каталог сервер берёт по адресу `CATALOG_URL`.
Модель: Claude Haiku 5.5 (`claude-haiku-5-5`). Счётчики в KV приблизительные, поэтому месячный лимит в консоли Anthropic тоже стоит выставить.

## Выкладка
- Демо (GitHub Pages): ветка `main`. В `index.html` и `admin.html` стоит `noindex`, `robots.txt` закрывает сайт от поиска.
- Финал (sksparts.kz): убрать `noindex` из `index.html` и `robots.txt`; в админке поменять адрес сайта не нужно — она работает с репозиторием.
- PRD и внутренние заметки в репозиторий не класть.
