# SKS PARTS — сайт-каталог

Чистый HTML/CSS/JS без библиотек и конструкторов. Сайт — `index.html`, каталог — `data/catalog.json`, фото — `img/`, админка — `admin.html`.

## Страницы
`#home`, `#about`, `#pick`, `#catalog` (фильтры в адресе: `?type=axial&tech=excavator&q=k3v`),
`#p-<id>` (товар), `#services`, `#contacts`. Ссылку на любую страницу можно отправить клиенту, кнопка «назад» работает.

## Админка — добавлять и менять товары
Адрес: **https://sksparts.kz/admin.html** (на сайте ссылки на неё нет).

Что умеет:
- **Товары:** добавить, изменить, дублировать, удалить; название, серия, тип, разделы каталога, применение, описание, коды на шильдике, кросс-номера (техника → номера → источник).
- **Фото товара:** несколько фото; первое — главное (видно в каталоге), остальные — галерея на странице товара; порядок меняется стрелками. Можно выбрать сразу несколько файлов — админка сама уменьшит до 900 px и сохранит в `img/`. У каждого фото своя подпись («фото серии», «фото похожего насоса» и т. п. или без подписи, если фото точное).
- **Категории:** типы насосов и разделы «по технике» — добавить, переименовать, поменять порядок, загрузить картинку (видна в плитках на главной), удалить. Тип нельзя удалить, пока в нём есть товары; раздел при удалении снимается с товаров.
- **Подбор по технике:** марки, модели и какие насосы на них подходят; синонимы марок для ИИ-помощника.
- **Резервная копия:** скачать каталог файлом и загрузить обратно.

Как работает: кнопка «Сохранить на сайт» записывает фото и `data/catalog.json` прямо в этот репозиторий через GitHub API. GitHub Pages пересобирает сайт, изменения видны через 1–5 минут. ИИ-помощник берёт каталог из того же файла.

### Вход по паролю
В админку входят **по паролю**. Ключ GitHub знает только владелец сайта: он хранится в `data/admin-access.json` зашифрованным этим паролем (PBKDF2-SHA256, 600 000 итераций → AES-GCM 256). Без пароля файл бесполезен.

**Первая настройка (владелец, один раз):**
1. Создать ключ GitHub: Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate new token; Resource owner — `sayt-kz`; Repository access — **Only select repositories** → `sks-parts`; Permissions → **Contents: Read and write**; срок — например, 1 год.
2. Открыть admin.html → внизу **«Настройка доступа (для владельца сайта)»**.
3. Вставить ключ, придумать пароль (не короче 10 символов), повторить → **«Сохранить пароль и войти»**.
4. Через 1–5 минут вход по паролю заработает. Пароль передать клиенту; ключ — никому.

**Смена пароля:** админка → вкладка **«Настройки»** → «Сменить пароль». Старый пароль перестаёт работать после обновления сайта.

**Полностью закрыть доступ** (если пароль или ключ мог утечь): создать в GitHub новый ключ → в «Настройках» сменить пароль и вставить новый ключ → удалить старый ключ в GitHub. Это отключит и тех, кто вошёл с галочкой «Запомнить».

Пароль надо выбирать надёжный: файл с зашифрованным ключом публичный, поэтому короткий пароль теоретически можно подобрать. 3–4 слова через дефис — хороший вариант.

## ИИ-помощник
- `AI_ENDPOINT = ""` в `index.html` → демо-режим, готовые ответы по каталогу.
- Боевой режим: развернуть `worker/` на Cloudflare Workers и вписать его адрес в `AI_ENDPOINT`.

```bash
cd worker && npm install
npx wrangler kv namespace create SKS_KV
npx wrangler secret put ANTHROPIC_API_KEY
npx wrangler deploy
```

Ключ API хранится только в секретах Worker, в коде страницы его нет.
Лимиты — в `wrangler.toml`: `MAX_MSG_PER_HOUR` (с одного IP) и `MONTHLY_LIMIT_USD`. Каталог сервер берёт по адресу `CATALOG_URL`.
Модель: Claude Haiku 5.5 (`claude-haiku-5-5`). Счётчики в KV приблизительные, поэтому месячный лимит в консоли Anthropic тоже стоит выставить.

## Выкладка
- Демо (GitHub Pages): ветка `main`. В `index.html` и `admin.html` стоит `noindex`, `robots.txt` закрывает сайт от поиска.
- Домен sksparts.kz подключён к GitHub Pages (файл `CNAME`). DNS у ps.kz: 4 записи A на 185.199.108–111.153, `www` → CNAME на основной домен; почтовые записи (`mail`, MX, SPF, DKIM) остаются на хостинге ps.kz.
- PRD и внутренние заметки в репозиторий не класть.
